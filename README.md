# Aether Creative — Video Portfolio

Static single-page portfolio site for **Aether Creative** — dynamic video editing services.

Originally built on Carrd; this repo is a self-contained mirror that can be hosted anywhere (GitHub Pages, Netlify, any static host).

## Contents

- `index.html` — the full page (styles + scripts inlined, same as the original build)
- `assets/images/` — local images used by the page
- Video gallery: 26 YouTube embeds + 1 TikTok embed (external iframes, work as-is)
- Font: Bangers (loaded from Google Fonts)

## Deploy

Push to GitHub and enable GitHub Pages, or drop the folder on any static host. No build step needed.
